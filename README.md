# Сайт-визитка Артема Журавлева

Чистые HTML и CSS, без JavaScript, сборки и зависимостей.

Откройте `index.html` в браузере. Две страницы используют общие стили в `styles.css`.
На телефоне страница занимает всю ширину, на компьютере — центральную колонку шириной до 430 px.

## Ссылки

В `index.html` и `awards.html` найдите элементы с `aria-disabled="true"`.
Добавьте нужный `href` и удалите атрибуты `aria-disabled`, `role` и `title`.
Для Telegram: `href="https://t.me/ВАШ_ЛОГИН"`.
Для электронной почты: `href="mailto:ВАШ_АДРЕС"`.
Остальные ссылки должны вести на ваше портфолио, канал и страницы награжденных проектов.
Адреса не были предоставлены, поэтому не подставлены вымышленные контакты.

## Фотографии

Подключены предоставленные оригиналы `assets/avatar.webp` и `assets/header-bg.webp`.
Основные цвета и максимальная ширина страницы находятся в `:root` файла CSS.

## GitHub Pages

Загрузите содержимое архива в корень репозитория, включая assets.
В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
Сборка и установка зависимостей не нужны.

Изображения оптимизированы в WebP: фон до 860 px (2× для колонки 430 px), аватар до 384 px.
